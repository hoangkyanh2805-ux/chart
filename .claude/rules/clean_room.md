# Rule: Nguyên tắc phòng sạch (Clean-Room Rule)

1. Cấm sao chép bất kỳ đoạn mã trực tiếp nào từ bundle hoặc file nguồn của ứng dụng gốc.
2. Mọi code mới phải được tạo ra từ đầu dựa trên đặc tả kỹ thuật trong `SPEC.md` và `contexte/`.
3. Biến, tên hàm và kiến trúc module phải tuân thủ chuẩn Clean Architecture và cấu trúc dự án của chúng ta.
